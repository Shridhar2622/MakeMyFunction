# Privacy Policy for MakeMyFunction

**Effective Date**: October 2, 2026

## 1. Overview
MakeMyFunction ("the Extension") is dedicated to keeping your source code and browsing activity completely private. The Extension is designed to work entirely client-side within your browser.

## 2. Information Collection and Storage
- **No Data Collection**: MakeMyFunction does NOT collect, store, or transmit any personal data, source code, browser history, or user identity information.
- **Local Storage**: The Extension uses `chrome.storage.local` exclusively to store non-sensitive user preferences, specifically your selected programming language preference (e.g., Java, C++, Python). This data never leaves your device.

## 3. Network and Code Privacy
- **Zero Remote Calls**: MakeMyFunction makes no HTTP/HTTPS network calls. It does not communicate with external servers, cloud services, analytics providers, or AI backends.
- **Local AST Analysis**: All code parsing, argument type resolution, and function generation take place locally inside your browser's JavaScript engine.

## 4. Third-Party Sharing
Because MakeMyFunction does not collect any data, no data is ever sold, shared, or disclosed to third parties.

## 5. Contact
For questions or issues regarding MakeMyFunction, please submit an issue on the project source repository.
